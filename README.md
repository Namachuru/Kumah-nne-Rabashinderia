Kumah-nne-Rabashinderia

A dragonfly wars game where a purple dragonfly strives to burn all green dragonfly enemies. hitting an enemy drains health but still kills the enemy.

---

Features
- Firebreathing purple dragonfly  
- Numerous green dragonfly enemies
- Health bar  

---

Tech Stack
- Java
